# JavaScriptAula

Repositório de estudos sobre JavaScript, com exemplos básicos de lógica de programação e controle de fluxo.

## Conteúdo

O arquivo principal do projeto é:

- `AprendendoJs.js`

Ele inclui exemplos de:

- Declaração de variáveis
- Uso de `let` e `const`
- Condicionais com `if` e `else`
- Operadores de comparação (`===`, `>`, `<`, `>=`, `<=`)
- Lógica combinada com `&&`, `||` e `!`
- Verificação de maioridade e acesso

## Como executar

No terminal, rode:

```bash
node AprendendoJs.js
```

## Objetivo

Este repositório foi criado para praticar conceitos fundamentais de JavaScript e aprender a escrever pequenos programas com tomada de decisão.
